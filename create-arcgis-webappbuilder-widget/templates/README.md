# Templates Usage

1. Copy this folder to a new widget directory under `client/stemapp/widgets/<WidgetName>`.
2. Rename `MyWidget` and `.jimu-widget-mywidget` identifiers.
3. Keep `manifest.json` flags aligned with files you actually include.
4. If no settings page is needed, set setting-related flags to `false` and remove `setting/`.
5. If no localization is needed, set locale-related flags to `false` and remove `nls/`.
