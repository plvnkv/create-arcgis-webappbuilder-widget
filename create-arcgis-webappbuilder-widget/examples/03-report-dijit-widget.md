# 03. Create a custom widget using the Report dijit

Reference: https://developers.arcgis.com/web-appbuilder/sample-code/create-a-custom-widget-using-the-report-diji.htm

## Use when

- Adding print/report output from map + tabular + HTML sections.
- You need a custom report button in an in-panel widget.

## Adaptation recommendations

- Keep report creation in `startup` and trigger `print` from a button handler.
- Move button text into localization files (`nls/strings.js`, `nls/uk/strings.js`).
- Keep report data generation in a dedicated method for easier testing.
- External image URLs in report HTML should be stable and HTTPS.

## Minimal code pattern

```js
define([
  'dojo/_base/declare', 'jimu/BaseWidget',
  'jimu/dijit/Report', 'jimu/dijit/PageUtils'
], function(declare, BaseWidget, Report, PageUtils) {
  return declare([BaseWidget], {
    baseClass: 'jimu-widget-report',

    startup: function() {
      this.inherited(arguments);
      this.report = new Report({
        footNotes: 'Report generated by widget',
        printTaskUrl: 'https://utility.arcgisonline.com/arcgis/rest/services/Utilities/PrintingTools/GPServer/Export%20Web%20Map%20Task',
        reportLayout: {
          pageSize: PageUtils.PageSizes.A4,
          orientation: PageUtils.Orientation.Landscape
        }
      });
    },

    _onBtnPrintClicked: function() {
      var printData = [{ type: 'map', map: this.map, addPageBreak: true }];
      this.report.print('Widget Report', printData);
    }
  });
});
```

## Validation checklist

- Report button works in deployed app build.
- Print service URL is reachable from runtime environment.
- Generated PDF includes expected sections and data.
- Localized button label is shown in target locale.
