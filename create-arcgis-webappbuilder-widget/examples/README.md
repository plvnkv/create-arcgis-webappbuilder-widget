# Web AppBuilder Example Recommendations

This folder contains implementation recommendations derived from official ArcGIS Web AppBuilder sample pages.

Use these docs as practical playbooks when implementing new widgets, themes, layouts, and integration behavior.

## How to use

1. Pick the closest sample file from the list below.
2. Apply its "Adaptation recommendations" to your target widget/theme.
3. Start from the minimal code pattern and then align naming with your project.
4. Verify using each file's checklist.
